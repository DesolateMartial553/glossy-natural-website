# Glossy Naturals

**Live site: [https://desolatemartial553.github.io/glossy-natural-website/](https://desolatemartial553.github.io/glossy-natural-website/)**

The website for **Glossy Naturals**, handmade natural skincare from Enugu, Nigeria: the range, product pages and ordering on WhatsApp.

- **Design:** Organic product-first
- **Built with:** plain HTML, CSS and JavaScript. No framework, no build step, self-hosted fonts and images.
- **Hosting:** GitHub Pages, served from the `master` branch.

To run it locally, open `index.html` in a browser, or serve the folder with `python3 -m http.server`.
